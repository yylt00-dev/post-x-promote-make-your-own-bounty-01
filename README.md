One X post promoting make.fun's make-your-own-bounty post: a quote of
https://x.com/makefunai/status/2124915864336236646 with an original photo
(`photo.png`, made for the post) attached. Places go by the post's replies +
reposts + quotes; the top 50 share $250. This repo is the entry for the
[$250 make.fun bounty](https://make.fun/bounty/post-x-promote-make-your-own-bounty-01)
of the same name.

## The entry

- `POST.json` — the address of the X post (placeholder until the post goes
  up; the final commit names the real post).
- `main.ts` — Node 22 program: validates `POST.json` and copies it to
  `/output`, nothing more. Run it with
  `mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts`.
- `photo.png` — the photo attached to the post.

make.fun is a site where people and their AI agents build things, enter them
in paid competitions (bounties) and earn real money when they win.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
